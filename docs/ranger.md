# 遊俠精靈（Sylvan Flutist）：角色與技能設計

> **狀態：已實作（2026-11-27）。**
> 本文件記錄實作後的規則與數值。數值以 `src/game/config.ts` 的 `CONFIG.ranger` 為準，勝率由無頭 AI 對 AI 模擬量測（第 6 節）。
> 最初的提案和實作之間有幾處差異，原因列在第 8 節。

---

## 1. 角色定位

| 項目 | 內容 |
|---|---|
| 一句話 | 以長笛召喚藤蔓與箭矢、從遠處收網的森林遊俠 |
| 強項 | 遠距離、哥布林中陷阱或被標記時 |
| 弱點 | 被哥布林貼身 |
| 控制能力 | 介於豎琴精靈（多目標主動控場）和紫晶精靈（單點爆發）之間；沒有任何暈眩或定身 |
| 強度 | 介於豎琴精靈和紫晶精靈之間，兩張地圖持平（見第 6 節） |

### 所有精靈都以樂器作為攻擊手段

這是整個遊戲的角色設定原則，之後新增的精靈也要遵守。

| 精靈 | 樂器 | 樂器怎麼變成技能 |
|---|---|---|
| 豎琴精靈 | 豎琴 | 琴聲吸引哥布林、凝視定身、近身打暈 |
| 紫晶精靈 | 小提琴 | 拉琴化為紫霧隱身、以琴弓衝鋒擊暈 |
| 遊俠精靈 | 長笛 | 吹笛召喚藤蔓陷阱、光箭與收網的繩索 |

遊俠最初的構想是弓手，定案改為**吹笛召喚箭矢**：她手上沒有弓，箭是笛聲凝成的光箭，在她面前胸口的高度出現後射出。

### 和其他精靈的對照

| | 豎琴精靈 | 紫晶精靈 | 遊俠精靈 |
|---|---|---|---|
| 讓哥布林可被捕獲的方式 | 凝視定身、近身擊暈 | 衝鋒擊暈 | **受困**（踩到陷阱，或被箭射中兩次） |
| 捕獲距離 | 2.8 m 內打包 | 2.8 m 內打包 | **4～12 m 用繩索收網**，近身不能收 |
| 哥布林救人的位置 | 精靈身邊（攪局） | 精靈身邊（攪局） | **被收網的隊友身邊**（割斷繩索） |
| 控制類型 | 主動，可同時控多隻 | 主動，單點爆發 | 被動（陷阱）加有條件的主動（箭） |
| 需要瞄準 | 凝視要對準方向 | 鎖定衝鋒不用瞄準 | 箭要瞄準，而且要中兩次 |

## 2. 核心規則：受困 → 遠距收網

遊俠**沒有暈眩和定身**，只能讓哥布林進入「受困」狀態，而且只有受困的哥布林可以被她收網。

**受困（snare）**

- 哥布林被藤蔓纏住不能移動，持續 3 秒。
- 進入方式：踩到已生效的藤蔓陷阱；或被箭射中時身上已經有「標記」或「減速」。
- 受困期間，遊俠在 4～12 m 內、視線可及時可以開始收網。收網開始後，哥布林一直被困到收網完成或被打斷。

**標記（mark）**

- 6 m 外被箭射中，或割斷繩索時獲得，持續 8 秒。
- 標記期間移動速度變成 60%，並顯示在遊俠的小地圖上。再中一箭就受困。

**救人的位置改變**

其他精靈的對局裡，救人要衝到精靈身邊攪局。遊俠收網時，隊友要跑到**被收網的哥布林身邊**按攪局割斷繩索。

## 3. 技能

沿用「3 個技能加捕獲」的鍵位。括號內是預設鍵。

### 3.1 藤蔓陷阱（Q）

| 項目 | 數值 |
|---|---|
| 施放 | 吹笛 0.35 秒，陷阱長在面前 1.3 m |
| 充能 | 最多 2 層，每 12 秒回 1 層 |
| 場上數量上限 | 3 個，超過時最舊的消失 |
| 生效延遲 | 1 秒 |
| 存在時間 | 45 秒 |
| 觸發半徑 | 1.1 m |
| 哥布林可見距離 | 3 m 內才看得到 |
| 觸發效果 | 受困 3 秒；在精靈小地圖顯示 4 秒 |
| 反制 | 哥布林在 3.2 m 內按攪局可以拆掉（進入攪局的冷卻） |
| 限制 | 受困或收網中的哥布林 4 m 內不能放 |

### 3.2 後躍撤步（E）

| 項目 | 數值 |
|---|---|
| 位移 | 0.38 秒內跳開 6 m |
| 方向 | 8 m 內有哥布林時，往遠離最近那隻的方向；否則往背後 |
| 附加效果 | 起跳位置留下一個陷阱，不消耗充能，0.4 秒後生效 |
| 冷卻 | 14 秒 |

追她的哥布林如果直線追上來會踩到陷阱，往旁邊閃就躲得掉。

### 3.3 召喚箭矢（F / 滑鼠左鍵）

吹笛 0.35 秒後，一支光箭朝畫面正前方射出。

| 項目 | 數值 |
|---|---|
| 射程 | 24 m，被牆、崖壁、孢子霧擋住 |
| 飛行速度 | 45 m/s |
| 冷卻 | 3 秒；射中哥布林時縮短為 1.5 秒 |
| 輔助瞄準 | 按下時準星 7° 內有哥布林就鎖定，射出時對準牠屆時的位置 |

| 命中時的情況 | 效果 |
|---|---|
| 目標在 6 m 內 | 只減速（速度 60%），持續 1.5 秒 |
| 目標在 6 m 外 | 標記 8 秒 |
| 目標已被標記、減速或受困 | 受困 3 秒 |

有哥布林受困、而且在收網距離內時，這顆鍵會變成收網（和其他精靈「擊暈鍵兼打包鍵」相同）。

### 3.4 收網（R / 滑鼠右鍵）

| 項目 | 數值 |
|---|---|
| 對象 | 受困中、視線可及的哥布林 |
| 距離 | 4～12 m；太近、太遠都不能收，畫面會提示 |
| 拖行 | 收網時以 10 m/s 把哥布林拖到身邊 2.5 m |
| 收網時間 | 短局版 3 秒、網站版 5 秒（豎琴的打包是 3 / 4 秒） |
| 冷卻 | 1 秒 |
| 被割斷時 | 進度全部保留（上限 85%），10 秒內再收網就接著算；遊俠踉蹌 0.5 秒 |
| 被大招掙脫 | 進度歸零；遊俠踉蹌 1.6 秒（和其他精靈相同） |

## 4. 近身弱點：貼身干擾

> **3 m 內有行動自如的哥布林時，她吹笛的速度（召喚箭、收網）減半。**

被困、被打包、已捕獲的哥布林不算。哥布林因此多了一種主動玩法：一隻貼身壓制遊俠，另一隻去割繩。

---

## 5. 哥布林的反制手段

| 遊俠的手段 | 哥布林怎麼應對 |
|---|---|
| 藤蔓陷阱 | 靠近時留意地上的藤圈；在旁邊按攪局拆掉 |
| 召喚箭矢 | 橫向走位、改變方向；被標記後 8 秒內找掩體 |
| 收網 | 跑到被收網的隊友身邊按攪局割斷繩索；或貼到遊俠 3 m 內拖慢收網；被收網的人可以用大招掙脫 |
| 後躍撤步 | 追擊時不要直線衝過她的起跳點 |

**割繩有代價**：割斷的藤蔓還纏在身上，割繩的哥布林和被救的隊友都會被標記 8 秒，再中一箭就受困。

## 6. 強度與平衡

### 6.1 量測方法

無頭 AI 對 AI 模擬（`tests/balance.test.ts`），種子 1000 起。「玩家速度」是把 AI 遊俠的移動速度換成玩家的 7.4，用來近似真人操控。

```bash
BALANCE=1 BAL_SHORT=1 BAL_MAP=meadow BAL_KIND=ranger BAL_VARIANT=ai BAL_N=48 BAL_OUT=out.jsonl npx vitest run tests/balance.test.ts
# BAL_RANGER='{"reel":{"time":4}}' 可以暫時覆寫 CONFIG.ranger 的數值；BAL_STATS=1 輸出各事件的次數
```

### 6.2 短局版（itch.io / CrazyGames，4 分鐘、7 隻哥布林）

精靈勝率，遊俠每格 192 場（2026-11-27）；豎琴與紫晶取自 `src/game/mushroomWorld.ts` 2026-11-26 的量測。

| | 草原 | 蘑菇秘境 |
|---|---|---|
| 豎琴・AI 精靈 | 0.74 | 0.74 |
| **遊俠・AI 精靈** | **0.80** | **0.78** |
| 紫晶・AI 精靈 | 1.00 | 0.96 |
| 豎琴・玩家速度精靈 | 0.93 | 0.89 |
| **遊俠・玩家速度精靈** | **0.94** | **0.93** |
| 紫晶・玩家速度精靈 | 0.99 | 0.99 |

遊俠落在豎琴和紫晶之間，兩張地圖的差距在 0.02 以內（192 場的誤差約 ±0.03）。

> `config.ts` 開頭註解裡的豎琴 0.35、紫晶 0.71 是 2026-11-18 的舊數字，提案當時以它為目標（AI 約 0.5）。地圖更新後的基準是上表，所以實作改以上表為準。

### 6.3 網站版（10 分鐘、8 隻哥布林）

遊俠每格 96 場（誤差約 ±0.05）；網站版的收網時間 5 秒、AI 速度 6.2、`aiHearChance` 0.02。

| | 草原 | 蘑菇秘境 |
|---|---|---|
| 豎琴・AI 精靈 | 0.44 | 0.43 |
| **遊俠・AI 精靈** | **0.70** | **0.74** |
| 紫晶・AI 精靈 | 1.00 | 1.00 |
| 豎琴・玩家速度精靈 | 0.66 | 0.76 |
| **遊俠・玩家速度精靈** | **0.79** | **0.93** |
| 紫晶・玩家速度精靈 | 1.00 | 1.00 |

AI 精靈兩張地圖持平。**玩家速度精靈在蘑菇秘境高出 0.14，還沒有拉平**，和豎琴在網站版既有的落差（0.66 對 0.76）同一個方向。試過的做法：收網時間 4 秒與 5 秒沒有差別；射程加到 26 m 也沒有拉近（0.74 對 0.92）。短局版有效的兩個旋鈕在網站版都不夠用，可能要從蘑菇秘境的地圖參數（`MUSHROOM_TUNE`）下手。

### 6.4 調整旋鈕

模擬中觀察到的影響，方便之後調整：

| 旋鈕 | 影響 |
|---|---|
| `arrow.range` | 主要影響草原。AI 的視野是 24 m，射程低於視野時草原勝率會驟降（23 m：0.62，24 m：0.80，26 m：0.94） |
| `reel.time` | 主要影響蘑菇秘境（救援者比較近）。短局版 AI 精靈在蘑菇秘境：2.5 秒 0.87，3 秒 0.78 |
| `arrow.markSlow` | 影響最大的單一數值。調整過程中（其他數值相同），玩家速度版在沒有減速時是 0.13～0.19，0.8 時 0.44，0.7 時 0.66 |
| `reel.pull` | 調整過程中，不拖行時平均每場只抓到 0.9 隻，拖行後 2.6 隻（救援者原本就在被困者旁邊） |
| `aiSpeed`、`aiAimError`、`aiHearChance` | 只影響 AI 遊俠當對手時的難度 |

### 6.5 已知的限制

1. **陷阱對 AI 哥布林的效果有限。** AI 遊俠每場放 8～12 個陷阱，只有 0.3～1 個抓到人。陷阱放在腳邊，AI 還不太會挑位置；真人玩家守洞口、傳送門時應該有用得多，但沒有量測過。
2. **面對抱團的哥布林很吃力。** 哥布林擠在她身邊輪流割繩時，她幾乎收不完。這符合「近身弱」的設計，但最終狩獵階段哥布林容易聚在一起。
3. **AI 哥布林不會主動貼身干擾**，只會割繩。貼身干擾目前只有真人玩家會用。

## 7. 實作

### 7.1 檔案

### 7.2 動作

`Idle`、`Walk`、`Run`、`Play`、`Shoot`（吹笛召喚箭，0.33 秒吹出）、`Plant`（吹笛放陷阱）、`Leap`（後躍）、`Capture`（收網）、`Victory`、`Stunned`。
笛子掛在右手的 `prop_flute` 骨；音符和繩索從喇叭口出來。

### 7.3 連線同步

- 房主判定，事件即時廣播：`rplant`、`trap`、`trapGone`、`draw`、`arrow`、`arrowHit`、`leap`、`leapEnd`，收網沿用 `pack` / `free` / `caught`。
- 快照只在精靈是遊俠時多送：精靈的充能與冷卻、每隻哥布林的受困 / 標記 / 減速、陷阱清單。豎琴與紫晶的對局訊息不變（原有的 golden 雜湊沒有變動）。
- 陷阱清單所有人都收得到，哥布林端只畫出 3 m 內的。這和紫晶隱身的做法相同，改過的客戶端看得到全部。

### 7.4 AI

- **遊俠**：看到目標就射（預判加上一點瞄準誤差），優先打已標記的；有受困的就走到收網距離收網；被貼身時後躍；經過洞口時放陷阱；巡邏時聽得到 45 m 內的哥布林。
- **哥布林**：隊友被收網時跑到牠身邊割繩（有 0.5～1.2 秒的反應時間）；靠近陷阱時有 55% 的機率注意到（逃命中 30%），注意到就繞開或拆掉。

## 8. 和最初提案的差異

| 提案 | 實作 | 原因 |
|---|---|---|
| 弓手 | 吹笛召喚箭矢 | 角色設定：所有精靈都用樂器 |
| 箭冷卻 5 秒、標記 5 秒 | 冷卻 3 秒（命中後 1.5 秒）、標記 8 秒 | 原數值下第二箭射出時標記已經消失，不可能連中兩箭 |
| 射程 22 m、沒有訂箭速 | 射程 24 m、45 m/s、命中半徑 0.6 m | 22 m 時草原勝率遠低於蘑菇秘境；較慢的箭 AI 有六成射不中 |
| 標記沒有其他效果 | 標記期間速度 60%、小地圖可見 | 沒有減速時她追不上被標記的哥布林，第二箭和收網都接不上 |
| 收網 4 / 5 秒，哥布林留在原地 | 3 / 5 秒，並把哥布林拖到身邊 | 留在原地時救援者就在旁邊，七成以上的收網被割斷；拖行後救援者要追上來 |
| 被打斷保留一半進度、硬直 1.2 秒 | 割繩保留全部進度（上限 85%）、踉蹌 0.5 秒 | 她沒有豎琴「琴聲吸引中不能攪局」這類反制救援的手段 |
| 沒有割繩的代價 | 割繩者與被救者都被標記 | 同上，讓救人有風險，她也接得上下一箭 |
| 待決定：要不要完全沒有暈眩 | **完全沒有** | 靠上面幾項補足強度，角色特色最鮮明；模擬的不變式也檢查遊俠的對局不會出現暈眩 |
| 待決定：陷阱是預判走位還是守點佈陣 | **兩者之間**：存在 45 秒、2 層充能、最多 3 個 | 守得住一兩個路口，也能在追逐中補放 |
| AI 勝率目標 0.5 | 0.78～0.80 | 目標所依據的基準數字是舊的，見 6.2 |
